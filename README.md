# 다중 지표 앙상블(Multi-Indicator Ensemble) 주식 스크리너

**6대 핵심 기술적 지표의 종합 가중치 평가 모델**을 기반으로, 코스피(KOSPI) 및 코스닥(KOSDAQ) 시장에서 정량적 점수가 **"매수 (BUY)"**에 해당하는 우량 기술적 반등/상승 종목을 정밀 발굴하는 웹 애플리케이션입니다.

---

## 📊 기술적 종합 점수 산출 기준 (가중치 100%)

| 순번 | 핵심 지표 | 가중치 | 만점 배점 | 주요 평가 로직 및 산출 기준 |
| :---: | :--- | :---: | :---: | :--- |
| **1** | **이동평균선 배열** | **25%** | **25점** | 단기(5)/중기(20)/장기(60)/초장기(120, 200) 정배열 완성도, 20일 생명선 상회 여부, 200일선 안착 |
| **2** | **MACD** | **20%** | **20점** | MACD선 vs 시그널선 골든크로스/상회 여부, 히스토그램 양봉 확장 탄력, 0선 상회 사이클 |
| **3** | **RSI (14)** | **20%** | **20점** | 50~70 안정적 매수 모멘텀 유지 구간(+), 30 이하 과매도 바닥권 탈출 반등(+), 70 이상 과매수 경계(-) |
| **4** | **볼린저 밴드 (20, 2)** | **15%** | **15점** | 중심선~상단 밴드 라이딩(0.5~0.85 %B)(+), 하단 밴드 이탈 후 과매도 지지 반등(+), 상단 돌파 과열(-) |
| **5** | **스토캐스틱 (Slow)** | **10%** | **10점** | %K와 %D선 골든크로스 발생 여부, %K의 %D 상단 위치 및 침체권 상향 돌파 모멘텀 |
| **6** | **거래량 (Volume)** | **10%** | **10점** | 20일 평균 대비 거래량 150% 이상 급증 + 양봉 형성(강한 매수 수급 유입), 거래량 수축 후 돌파 |
| **합계** | **6대 다중 지표 앙상블** | **100%** | **100점** | **종합 점수: -100점 ~ +100점 (매수 BUY 기준: +45점 이상)** |

### 투자 의견 판정 기준
- **매수 (BUY)**: 종합 점수 **+45점 이상**
- **비중확대 (OVERWEIGHT)**: 종합 점수 **+15점 ~ +44점**
- **중립 (NEUTRAL)**: 종합 점수 **-14점 ~ +14점**
- **비중축소 (UNDERWEIGHT)**: 종합 점수 **-44점 ~ -15점**
- **매도 (SELL)**: 종합 점수 **-45점 이하**

## 🚀 빠른 실행 방법

### 방법 1. 원클릭 배치 파일 실행 (Windows)
폴더 내 `run_app.bat` 파일을 더블 클릭하면 브라우저에서 스크리너 대시보드가 자동으로 열립니다.

### 방법 2. 터미널 명령어로 실행
```bash
streamlit run app.py
```

---

## 📁 프로젝트 파일 구성

- **`app.py`**: `00 Bookmarks` 스타일의 세련된 다크 테마 대시보드 UI (사이드바, 타이틀 배너, KPI 카드, 엑셀 테이블, 퀵 차트 뷰어)
- **`engine.py`**: 멀티스레딩(24 workers) 기반 코스피/코스닥 전 종목 초고속 데이터 수집 및 스크리닝 엔진
- **`indicators.py`**: 6대 핵심 기술적 지표 계산 및 개별/종합 가중치 점수 산출 모듈
- **`excel_exporter.py`**: 전문가용 스타일 서식 엑셀(.xlsx) 및 CSV 파일 생성 모듈
- **`run_app.bat`**: 원클릭 간편 실행 스크립트
- **`requirements.txt`**: 의존성 패키지 목록
